# Prompts used to build Week 2 projects

## Common prompt
Act as a practical software engineer and beginner-friendly teacher. Build a small offline-first project using plain HTML, CSS and JavaScript unless the platform requires otherwise. Keep the code readable, avoid paid APIs and login requirements, validate inputs, explain how to run it, and provide a manual test checklist. Do not claim a feature works unless it has been implemented.

## Project 2 — Form Photo Fixer
Build a browser-based image preparation tool. Allow a user to choose an image, preview it, crop it to a portrait aspect ratio, select a preset/custom pixel size and download a JPEG. Display the output dimensions and estimated file size. Keep processing in the browser.

## Project 3 — Resume Builder
Build a resume editor with form fields, live A4-like preview, three visual templates, editable sections, JSON save/load and print-to-PDF. Make the text selectable in the printed PDF and support long resumes across pages.

## Project 7 — Bill Book
Build an offline-first shop billing page with editable shop details, item catalogue, quantity, discount, tax, automatic totals, printable/shareable bill and saved bill history. Use sample data only; never initiate a real payment.

## Project 8 — Auto Rally
Build a mobile-friendly HTML canvas auto-rickshaw racing game with touch and keyboard steering, coins, obstacles, three laps, timer, sound toggle and locally saved best time. Make it playable offline after loading.

## Project 10 — Job Clipper
Build a Chrome Manifest V3 extension. Let the user manually enter role, company, job URL and deadline; save cards in local storage; edit status across Saved/Applied/Interview/Result; search and export CSV. Keep manual entry available if page extraction fails.

## Project 13 — Style Spy
Build a Chrome Manifest V3 extension that reads computed styles from the active page, ranks common visible colours, lists fonts/weights/sizes, copies CSS variables and saves named style kits locally.

## Project 16 — Your Own Skill
Create a reusable viva skill that reads supplied notes, asks one question at a time, evaluates answers, tracks score and gives page/topic-based revision advice. Include instructions and sample tests.

## Project 17 — Same Page, New Design
Create a plain page and a redesigned responsive page for the same fictional event. Preserve all visible wording exactly. Explain three design changes and why they improve usability.
