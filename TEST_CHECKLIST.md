# Manual test checklist before submission

- [ ] Open every web project with Wi-Fi turned off after its first load.
- [ ] Form Photo Fixer: use a large sample image; check downloaded dimensions and file size in file properties.
- [ ] Resume Builder: enter enough text for two pages; print to PDF; select/copy text from the PDF; reload saved JSON.
- [ ] Bill Book: calculate at least five sample bills by hand and compare totals; reload and confirm history remains.
- [ ] Auto Rally: finish a race on a phone; test steering, collisions, laps, mute and saved best time.
- [ ] Job Clipper: install unpacked; add/edit/search jobs; export CSV and open it in a spreadsheet; test on three job sites if automatic extraction is added.
- [ ] Style Spy: install unpacked; inspect five websites; compare colours/fonts manually; save and reload a kit.
- [ ] Viva skill: test on three different note files in a fresh agent session; compare results with using no skill.
- [ ] Same Page, New Design: compare all text in before.html and after.html; test the redesigned page on a phone.
- [ ] Add genuine screenshots of your own tests and your name/college details if required by the portal.
