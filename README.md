# Week 2 GenAI Internship — Project Submission Pack

Prepared as beginner-friendly starter implementations for the eight-project minimum (two projects from each of four sections).

## Projects included
1. Form Photo Fixer — browser image resize/crop and download prototype.
2. Resume Builder — live resume preview, templates, JSON save/load, print-to-PDF.
3. Bill Book — offline-capable billing prototype with item totals, tax/discount, history and printable bill.
4. Auto Rally — mobile-friendly HTML5 canvas racing game.
5. Job Clipper — Chrome extension popup for manually saving and tracking job applications.
6. Style Spy — Chrome extension popup that inspects the active page's colours and fonts.
7. Your Own Skill — reusable `/viva` skill instructions and sample input/output.
8. Same Page, New Design — before and redesigned pages with identical text.

## How to run
- Projects 1–4 and 8: open each `index.html` in Chrome/Edge. No server or API required.
- Projects 5–6: Chrome → `chrome://extensions` → enable Developer mode → Load unpacked → select the project folder.
- Project 7: copy the `viva` skill folder into the skills directory supported by your AI agent. Skill folder conventions differ by agent; see its README.

## Important submission note
This is a working prototype pack, not proof that every rubric item has been independently tested. The PDF asks you to test each project's “Done when” checklist. In particular, verify phone installation/offline behaviour, extension behaviour on multiple websites, and exported files on your own device. Do not claim tests you have not performed. Add your own screenshots and details before portal submission.
